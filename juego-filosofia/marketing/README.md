# Material para redes

- `trailer-vertical.mp4`: tráiler de 32 s en 1080x1920 (9:16) para TikTok, Instagram Reels y YouTube Shorts. Lleva música, 30 fps y está normalizado a −14 LUFS.
- `portada.jpg`: fotograma de cierre, para usar como miniatura.
- `clips/`: retratos animados de 5 s (Sócrates, Hipatia, Nietzsche, Sor Juana, Buda), en formato cuadrado de 720 px y sin audio, para publicaciones sueltas.
- `herramientas/`: scripts con los que se hizo el tráiler. Las capturas del juego se tomaron con Playwright; el montaje se hizo con ffmpeg y PIL.

Los retratos animados se hicieron con Kling 2.5 (imagen a video) y la música con Suno; ambos se generaron en kie.ai a partir de los retratos al óleo del juego. Las rutas de `compose.py` apuntan a la carpeta de trabajo donde se generó: es una referencia, no un paso de compilación.
